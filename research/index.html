    Graph AI

    Advancing graph and hypergraph neural networks and graph GenAI, with a focus on robustness, efficiency, and interpretability.

    Surface Cues Over Structure: Probing LLM Behavior on Brain Connectivity Graphs

    BigData 2026LLMs on GraphsBrain Networks

    Can LLMs actually reason over brain connectivity graphs? Through a controlled study of ADHD diagnosis from resting-state fMRI connectivity, this work shows that six LLMs, from small open-weight models to a recent proprietary one, follow surface cues such as region names, number formatting, and prompt framing rather than the subject’s connectivity.

    How it worksEach subject’s rs-fMRI is turned into a brain graph, with brain regions as nodes and functional connectivity as edges, and given to the LLM as text. Five probes then test the knowledge source, statistical context, structure identification, perturbation sensitivity, and whether the model’s justifications match the data.

    HyperGCL: Multi-Modal Graph Contrastive Learning via Learnable Hypergraph Views

    IJCNN 2025Hypergraph GCLMultimodal LearningAdaptive Augmentation

    HyperGCL constructs three complementary hypergraph views from structure and attributes, then applies a learnable, topology-aware augmentation. A network-aware contrastive loss aligns the views while preserving important relations and filtering noise.

    How it worksSystem architecture of HyperGCL. Three hypergraph views are built from the input graph and node attributes, a learnable augmentation generates adaptive views, view-specific encoders learn each view, and a network-aware contrastive loss is combined with a supervised loss to train the model.

    Topology-Guided Hypergraph Transformer Network: Unveiling Structural Insights for Improved Representation

    PRICAI 2025Stanford Graph Learning Workshop 2024Graph TransformerStructure-Aware Attention

    THTN represents subgraphs as hyperedges to capture higher-order relations, and uses a structure-aware attention that jointly weighs semantic and topological cues. A structural–spatial encoding module adds graph topology and spatial context to node embeddings, capturing both local and global dependencies.

    How it worksTHTN combines structural and spatial encoding, which enriches node features, with structure-aware attention, which brings the structural importance of nodes and hyperedges into attribute-based semantic attention.

    Graph Mining & Network Science

    Discovering patterns, communities, and dynamics in large-scale, complex, heterogeneous networks.

    Does Graph Compression Preserve Signal Propagation?

    ICMLA 2026Graph CompressionOversmoothing

    Graph compression makes graph learning cheaper, but does it keep how signals spread through the graph? Studying coarsening and sparsification across five datasets, this work finds a consistent trade-off: coarsening follows the original propagation more faithfully but oversmooths more, while sparsification keeps signals diverse but drifts further from the original as depth grows.

    How it worksNode features are propagated on the original and compressed graphs at increasing depths, and the two are compared using deviation from the original trajectory, Dirichlet energy, and numeric rank. The figure shows the deviation for coarsening (dashed) and sparsification (solid) methods.

    Enhancing GNN Representations via Homophily-Aware Subgraphs with Multi-Objective Learning

    DSAA 2026k-trussSubgraph Contrastive Learning

    GNNs lose information when signals from different classes mix during long-range propagation. HASCL splits the graph into tightly connected k-truss subgraphs, which keep strong homophily, and learns node representations that stay consistent with their own subgraph. It outperforms 15 baselines on node classification across eight homophilic and heterophilic datasets.

    How it worksThe graph is decomposed into k-truss subgraphs; a GCN learns node embeddings and SAGPool learns subgraph embeddings. Positive and negative subgraph views, made by shifting subgraph indices or adding RealNVP-based noise, drive a contrastive loss that is trained jointly with a supervised loss.

    Tackling Oversmoothing in GNN via Graph Sparsification

    ECML PKDD 2024Truss-based PruningOversmoothing

    TGS uses truss decomposition to prune redundant edges from dense graph regions. This preserves essential topological structure while preventing the excessive feature mixing that causes oversmoothing in deep GNNs.

    How it worksTruss decomposition-based edge pruning framework for graph sparsification to tackle oversmoothing.

    AI for Biomedicine

    Applying graph-based AI to drug discovery, drug repurposing, bioinformatics, and health data analytics.

    Fin-H2AN: Fingerprint-based Heterogeneous Hypergraph Attention Network for Molecular Property Prediction

    DSAA 2026Molecular FingerprintsHeterogeneous Hypergraph

    Fin-H2AN predicts molecular properties by placing all molecules and the substructures from three molecular fingerprints (MACCS, ErG, and PubChem) into one heterogeneous hypergraph. This captures higher-order relations between molecules that standard GNNs miss, and it achieves the best average rank against state-of-the-art models on MoleculeNet benchmarks.

    How it worksEach fingerprint bit becomes a node and each molecule becomes a hyperedge connecting its active bits. A dual attention network first passes molecular context to the fingerprint nodes, then gathers the most relevant nodes of each fingerprint type into a molecule embedding for prediction.

    Fragmentation-Based Hypergraph Attention Network for Molecular Classification Tasks

    Complex Networks 2025BRICS FragmentsHyperGNN

    Instead of processing each molecule as a separate graph, this work places all molecules into one hypergraph built from chemically meaningful fragments. Molecules that share fragments become directly connected, which improves molecular property prediction and trains far faster than standard GNNs.

    How it worksMolecules are broken into retrosynthetically meaningful fragments with BRICS. Each fragment becomes a node and each molecule a hyperedge, and a dual attention network passes information between fragments and molecules to learn molecule embeddings.

    HeTAN: Heterogeneous Graph Triplet Attention Network for Drug Repurposing

    DSAA 2024Drug RepurposingTriplet Attention

    HeTAN models interactions among drugs, targets, and diseases together. Triplet message passing and triplet-wise attention capture higher-order relationships beyond pairwise links, uncovering meaningful drug–target–disease associations.

    How it worksHeTAN builds a heterogeneous network of drug, target, and disease nodes, learns node representations with triplet message passing and triplet-wise attention, and predicts drug–target–disease interactions with an MLP.

    HyGNN: Drug-Drug Interaction Prediction via Hypergraph Neural Network

    ICDE 2023Drug–Drug InteractionHyperGNN

    HyGNN predicts drug–drug interactions from SMILES alone by building a hypergraph of molecular substructures. It outperforms baselines on F1, ROC-AUC, and PR-AUC and generalizes to new, unseen drugs.

    How it worksHyGNN builds a hypergraph where each drug is a hyperedge and frequent chemical substructures are nodes, then learns drug representations with an attention-based hyperedge encoder and predicts interactions with a decoder.

    Drug Abuse Detection in Twitter-sphere: Graph-Based Approach

    BigData 2021Health Data AnalyticsText Graphs

    This work detects drug abuse events on social media by building corpus- and document-level text graphs from Twitter data. GNN-based models outperform traditional machine learning and deep learning approaches at identifying drug abuse-related content.

    How it worksGraph-based drug abuse detection: data collection and preprocessing, corpus- and document-level text graph construction, and GNN-based classification of drug abuse-related tweets.

    Effects of COVID-19 on Individuals in Opioid Addiction Recovery

    ICMLA 2021Health Data AnalyticsSocial Media

    Analyzing Twitter data, this study finds a 30% drop in medication-assisted treatment (MAT) use and more mentions of illicit opioids during COVID-19, highlighting relapse risks and the need for continued care.

    How it worksFive-step framework for analyzing the impact of COVID-19 on active MAT medicine users using Twitter data.

    Sequence & Multimodal Learning

    Modeling sequential, temporal, and multimodal data for event prediction, genomics, and vision–language reasoning.

    DyGCL: Dynamic Graph Contrastive Learning for Event Prediction

    BigData 2024Dynamic GNNEvent Prediction

    DyGCL captures both fine-grained node dynamics and the overall structural evolution of a graph through local and global view encoders. Contrastive learning and attention-based fusion let it model temporal patterns effectively across real-world datasets.

    How it worksDyGCL feeds dynamic graphs into a local-view encoder (dynamic node representations) and a global-view encoder (graph pooling with an LSTM), aligns them with contrastive learning, and combines them for event prediction.

    Seq-HyGAN: Sequence Classification via Hypergraph Attention Network

    CIKM 2023Sequence AnalysisHyperGNN

    Seq-HyGAN models higher-order relationships among subsequences for sequence classification. Attention-based learning captures both local and global dependencies, producing richer representations than existing approaches.

    How it worksSeq-HyGAN builds a hypergraph where each sequence (e.g., DNA) is a hyperedge and frequent subsequences are nodes, then learns sequence representations with attention on the important subsequences.
